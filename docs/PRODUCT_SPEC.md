# CarbonLoop

## INPUT
- waste type
- quantity
- location
- availability date
- optional moisture
- optional quality

## OUTPUT
- compatible facilities
- match score
- recommended facility
- route
- transport cost
- estimated carbon impact
- conversion output
- carbon ledger record
- economic value

## MVP

1. Add waste lot
2. Find compatible facilities
3. Rank facilities
4. Display them on GIS map
5. Calculate route
6. Calculate carbon impact
7. Create Carbon Ledger record
8. Show economic value

## NOT MVP

❌ Real carbon-credit issuance
❌ Blockchain
❌ Real payments
❌ Full fleet management
❌ Multi-stop VRP
❌ Complex ML
❌ Real municipal authentication
❌ Production-grade IoT
